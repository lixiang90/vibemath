# P_6(4) 正式启动：两条对角四次曲线的第一闸门

日期：2026-09-03  
范围：只做精确等价、边界、有限局部类、自同构和 genus-1 商入口；没有高度搜索，也没有声称求完有理点。

## 1. 与六项等差数列的精确等价

设六项有理等差数列为 A_j=A_0+jd，且第 0、i、5 项分别为 X^4、Y^4、Z^4。消去 d 得

    (5-i)X^4+iZ^4=5Y^4,                           (1)
    d=(Z^4-X^4)/5.

反之，(1) 的任一有理点都按上述 d 构造一个在位置 0、i、5 为四次幂的等差数列。若 X^4=Z^4，则 (1) 还强迫 Y^4=X^4，所构造的是常数列；其余点给非恒定列。

Hajdu--Tengely 已处理跨度不超过 4 的位置型。对仍可能跨满六项的三位置型，反射 i 与 5-i 后只剩 i=1,2，即

    C1: 4X^4+Z^4=5Y^4       （位置 0,1,5），
    C2: 3X^4+2Z^4=5Y^4      （位置 0,2,5）。

因此在引用其短跨度结论的前提下，证明 C1、C2 只有 X^4=Y^4=Z^4 的点即可推出 P_6(4)=2。这个“只有两条曲线”的归约不是本轮重新声称的独立 prior-art 结果。

## 2. 光滑性、零坐标和无穷远

两条曲线都是光滑平面四次曲线，故 genus 为 3。偏导分别是常数乘 X^3、Y^3、Z^3，在特征零中不可能同时于射影点消失。

每条曲线都有四个平凡射影 Q-点

    [+-1:+-1:+-1] / 整体变号，

它们均对应常数等差数列。

不存在零坐标 Q-点：

- Y=0 时左侧是正实数之和；
- C1 的 X=0 或 Z=0 分别要求 5 或 5/4 是有理第四幂；
- C2 的 X=0 或 Z=0 分别要求 5/2 或 5/3 是有理第四幂；
- 以上均由相应素数赋值不被 4 整除而排除。

因此所有 Q-点都在 Y!=0 的仿射图中。几何上 Y=0 各有四个无穷远点，但没有 Q-有理无穷远点。

## 3. 第一批局部四次幂类

把有理点缩放为 primitive 整数三元组。精确剩余类枚举与赋值论证给出：

| 曲线 | Q_2 必要条件 | Q_5 必要条件 | Q_3 必要条件 |
|---|---|---|---|
| C1 | X,Y,Z 全奇 | X,Z 为 5-adic units | 暂无额外记录 |
| C2 | X,Y,Z 全奇 | X,Z 为 5-adic units | Y,Z 为 3-adic units；X 可被 3 整除 |

其中 2-adic 结论由模 16 的第四幂类 {0,1} 得到。模 5 先给 `5|X iff 5|Z`；若两者都被 5 整除，方程两侧的 5-adic 赋值与 primitive 性矛盾。C2 模 3 同理给 `3|Y iff 3|Z`，两者同时整除又强迫 X 整除 3。

这些只是必要局部条件，不是 everywhere-local-solubility 分类。下一步应在 Q_2、Q_3、Q_5 上枚举覆盖的实际像，而不是继续增加搜索高度。

## 4. 自同构、三个 genus-1 商与 Jacobian 入口

由于只出现第四幂，坐标独立变号模整体变号给出一个 Q-有理 Klein 四群。这里只声称这个可见子群，不声称它是完整 Q-自同构群。

每个非平凡变号 involution 固定四个几何点。Riemann--Hurwitz 给商曲线 genus 1。取适当仿射图及平方不变量，得到：

### C1

| involution | genus-1 四次模型 | Jacobian 候选 |
|---|---|---|
| X -> -X | V²=5-Z⁴ | v²=u³+20u |
| Z -> -Z | V²=5-4X⁴ | v²=u³+80u |
| Y -> -Y | V²=20+5Z⁴ | v²=u³-400u |

### C2

| involution | genus-1 四次模型 | Jacobian 候选 |
|---|---|---|
| X -> -X | V²=15-6Z⁴ | v²=u³+360u |
| Z -> -Z | V²=10-6X⁴ | v²=u³+240u |
| Y -> -Y | V²=15+10Z⁴ | v²=u³-600u |

这里使用标准事实：`V²=a x⁴+b` 的 Jacobian 是 `v²=u³-4ab u`。三个 commuting involution 的 Kani--Rosen 分解给出

    Jac(C_i)  ~_Q  E_{i,1} x E_{i,2} x E_{i,3}.

代码还在 p=7,11,13,17,19 对两边做逐点计数，验证

    #C_i(F_p)=p+1-sum_j a_p(E_{i,j}),

从而独立拦截四次 twist 或符号错误。有限域点数核对是公式审计，不替代商映射/Kani--Rosen 证明。

## 5. 下一步与证据闸门

`PAPER_CUBE_P6_elliptic_quotients.m` 为六个椭圆因子准备了 rank/torsion 入口，但本机没有 Magma/Sage，仓库中没有真实输出。当前严格状态仍为：

    C1(Q), C2(Q) 完整点集未知；P_6(4) 未决定。

下一阶段的最低成本任务：

1. 给六个 genus-1 商写出原曲线到商及商到 Jacobian 的完整映射；
2. 审计六个椭圆因子的同构/同源去重、解析秩与严格 rank bounds；
3. 对每个商点求纤维的平方/第四幂提升条件，形成有限 covering collection；
4. 只在获得有限指数、饱和 Mordell--Weil 子群后启动 elliptic Chabauty 或 MW sieve。

若至少一条曲线的三个因子均低秩且提升覆盖有限，继续并优先闭合该曲线。若两条曲线都出现未饱和高秩因子且覆盖数爆炸，则在第一个完整覆盖证书处停下，不用高度搜索冒充证明。
