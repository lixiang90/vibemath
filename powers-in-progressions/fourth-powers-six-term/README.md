# Six-term fourth-power project

This long-term project records exact reductions, six genus-one quotients,
quartic-to-Jacobian maps, covering identities, and a genus-five reduction
related to the six-term fourth-power problem.

The structural identities and tests are reusable.  No complete rational-point
classification, rank/saturation certificate, or decision of `P_6(4)` is
claimed.
