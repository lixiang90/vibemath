# Author contributions — placeholders requiring approval

Using the CRediT vocabulary where accepted:

- `<<AUTHOR 1>>`: Conceptualization; Formal analysis; Methodology; Validation;
  Writing — original draft; Writing — review and editing.
- `<<AUTHOR 2, IF ANY>>`: `<<APPROVED ROLES>>`.
- `<<CORRESPONDING AUTHOR>>`: Project administration; Data curation; Software;
  Reproducibility package; Correspondence.

Every listed author must have made a qualifying contribution, approved the
submitted version, agreed to be accountable for their part, and approved the
AI-use disclosure. Remove unused roles and do not infer contributions from
file history or conversation participation.
