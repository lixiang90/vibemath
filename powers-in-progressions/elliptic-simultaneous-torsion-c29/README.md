# Simultaneous torsion and the C29 curve

This long-term project gives an explicit genus-two model for a simultaneous
torsion fibre product and audits the birational maps, exceptional fibres,
cusps, discriminant, and Igusa--Clebsch data.

The frozen certificate contains exact polynomial data only.  It does not prove
the Mordell--Weil rank or the complete rational-point set.
