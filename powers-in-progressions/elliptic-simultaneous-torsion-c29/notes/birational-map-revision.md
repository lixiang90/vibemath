# C29 审稿阻断修订

日期：2026-09-03  
对应代码：`PAPER_CUBE_C29_model.py`、`PAPER_CUBE_C29_test_model.py`。

## 1. 两侧复合与主开集

沿用

    F(r,k)=k(r^3-3r^2+1)-(1+4k^3)r(r-1)=0

及双曲模型

    Y^2=f(z),
    f=z^6+2z^5+15z^4-20z^3+15z^2+18z+33.

正向映射为

    z=(4kr+r-2k-2)/(r+2k),
    Y=4(1-z^2)(k+1/(2k));

反向映射为

    k=(z^3+z^2-9z-1-Y)/(8(z^2-1)),
    r=2(kz+k+1)/(4k-z+1),
    s=(1-8k^3)/(1+4k^3).

代码现同时核验：

1. 正向代入后 `Y^2-f(z)` 的分子模 F 为零；
2. 反向代入后 F 的分子模 `Y^2-f(z)` 为零；
3. 从源侧出发的 k、r 两个复合均模 F 等于恒等；
4. 从目标侧出发的 z、Y 两个复合均模 `Y^2-f(z)` 等于恒等。

双有理主开集须同时删除以下分母的零点：

    源侧：D(r), s+2, k, r+2k;
    目标侧：z^2-1, 4k-z+1, 1+4k^3.

在下降推导的中间图上还出现 `z+d`、`p-1`、`X-A`、`L_k`；它们是 Cayley/Kummer 图的边界。除下面六个 cusp 外，其余以倒数图或分支局部参数延拓，并不形成额外曲线分量。这里的列表描述公式成立的稠密主开集，不声称每个因子的零点都是正规化上的不同点。

模 5 不可约测试也已修订为结构判据：factor-list 必须恰有一个次数 6、指数 1 的因子；不再依赖多项式的字符串打印形式。

## 2. 六个 cusp 的局部参数与 6 对 6 表

令 ε 为局部参数。对 k=0 的三个正规化分支，精确递推得到

    r=0:      r=-ε+ε²+ε³-2ε⁴+O(ε⁵),
    r=1:      r=1-ε+2ε²-2ε³+ε⁴+ε⁵+O(ε⁶),
    r=infty:  1/r=ε-2ε²+2ε³-ε⁴-ε⁵+O(ε⁶),

其中 k=ε、s=1+O(ε³)。对 k=infty，取 k=1/ε：

    r=0:      r=-ε²/4+ε⁴/16+ε⁵/16+ε⁶/64-ε⁷/32+O(ε⁸),
    r=1:      r=1-ε²/4+ε⁴/8+ε⁵/16-ε⁶/32-ε⁷/16+O(ε⁸),
    r=infty:  1/r=ε²/4-ε⁴/8-ε⁵/16+ε⁶/32+ε⁷/16+O(ε⁸),

且 s=-2+O(ε³)。代入正向映射得到：

| k 边界 | (r,s) | H29 上的点 | 局部主项 |
|---|---|---|---|
| 0 | (0,1) | infinity+ | z=-2/ε-1+O(ε²), Y/z³ -> +1 |
| 0 | (1,1) | (-1,8) | z=-1+2ε+O(ε²) |
| 0 | (infinity,1) | (1,-8) | z=1+2ε+O(ε²) |
| infinity | (0,-2) | (-1,-8) | z=-1-ε+O(ε²) |
| infinity | (1,-2) | (1,8) | z=1-ε+O(ε²) |
| infinity | (infinity,-2) | infinity- | z=4/ε-1+O(ε²), Y/z³ -> -1 |

代码用有理级数代入 F、极限及无穷远符号逐项核验这张表；点由代数对象/有理数元组比较，不靠字符串。

## 3. Igusa--Clebsch 型绝对指纹

为避免不同软件归一化常数造成歧义，代码明确采用未归一化二元 transvectant

    (G,H)_m=sum_i (-1)^i binom(m,i)
      d^mG/(dx^(m-i)dz^i) d^mH/(dx^i dz^(m-i)).

对齐次六次式 F，定义

    I2=(F,F)_6,
    G=(F,F)_4, I4=(G,G)_4,
    H=(F,G)_4, I6=(H,H)_2,
    I10=disc(f).

精确值为

    I2  = 33177600,
    I4  = 26418075402240000,
    I6  = 876488338465357824000000,
    I10 = -2849934139195392.

相应 GL2/整体缩放不变的查重元组为

    (I4/I2², I6/I2³, I10/I2⁵)
      =(24,24,-1/(2^25*3^16*5^10)).

这是本仓库的规范化同构检索键；与 Magma/LMFDB 比较时必须先按各自约定换算，不能直接比较未经说明的 `IgusaClebschInvariants` 四元组。`PAPER_CUBE_C29_isomorphism_gate.m` 提供候选曲线的正式 `IsIsomorphic` 入口；当前没有候选数据库或真实 transcript，因此查重状态仍为未完成。

## 4. rank/Chabauty 闸门修订

旧版“rank upper bound <2 即继续”不充分。新闸门要求同时满足：

1. `RankBounds(J)` 给出严格上界至多 1；
2. 已知除子生成的子群达到同一秩；
3. 获得有限 index bound，并对所有可能整除该指数、以及后续 Mordell--Weil sieve 使用的素数完成饱和；
4. 点到 Jacobian 的基点、局部像和回映射均经审计；
5. `PointsGenus2`/Chabauty 返回明确的 proven 状态。

仅有秩区间、未饱和生成元或高度搜索均不能推出 C29(Q) 完备。由于本机无 Magma/Sage，本轮停止 C29 算术推进并正式转入 P_6(4) 闸门。
