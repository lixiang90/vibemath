# BST 整点等差列方法与低次数域平方幻方

## 1. 任意数域上的精确等价

设 `K` 是特征不为 2 的数域，`n in K*`，并令

```text
E_n : y^2 = x(x^2-n^2) = (x+n)x(x-n).
```

每个三阶幻方都可唯一写成（旋转、反射不影响结论）

```text
 a-b      a+b+c      a-c
 a+b-c      a       a-b+c
 a+c      a-b-c      a+b
```

线和为 `3a`。取

```text
X_0=a-b,  X_1=a,  X_2=a+b,
```

则 `X_0,X_1,X_2` 是公差 `b` 的等差列，而九个幻方项恰是三个集合

```text
{X_i-n, X_i, X_i+n},  i=0,1,2
```

（取 `n=c`）的并。

若 `P=(u,v) in E_n(K)`，倍点公式给出

```text
x(2P)   = (u^2+n^2)^2/(4v^2),
x(2P)+n = (u^2+2nu-n^2)^2/(4v^2),
x(2P)-n = (u^2-2nu-n^2)^2/(4v^2).
```

反过来，满 2-下降的 Kummer 判据（零坐标按扭点惯例解释）是

```text
Q=(X,Y) in 2E_n(K)
    iff X-n, X, X+n are all squares in K.
```

所以，下列两件事等价：

1. `K` 中存在九项互异的三阶平方数幻方；
2. 某条 `E_n/K` 上存在三个点 `Q_0,Q_1,Q_2 in 2E_n(K)`，其
   `x` 坐标构成非平凡等差列，而且九个 `X_i-n,X_i,X_i+n` 互异。

这不是只对 `Q` 成立；二次域、三次域的条件完全相同。若还要求幻方
平方根是代数整数，则再要求 `n,X_i in O_K`。此时 `Y_i` 是三个平方根
的乘积，也在 `O_K` 中。反向同样成立，因为 `alpha^2 in O_K` 蕴含
`alpha` 满足首一多项式 `T^2-alpha^2`，故 `alpha in O_K`。

## 2. BST 论文实际证明了什么

Bremner--Silverman--Tzanakis 研究 `n` 为平方自由正整数时的

```text
E_n/Q : y^2=x(x^2-n^2).
```

其主定理比“曲线秩一”更强：`E_n(Q)` 的任何秩一子群都不含非平凡的
整点三项 `x` 等差列。因此，一个有理平方幻方若存在，对应三个点所生成
的子群至少有秩二。

证明路线是：

1. 对 `x(P)=a/d^2` 建立显式 Néron--Tate 高度上下界；
2. 在秩一子群中写 `P_i=m_iP+T_i`，用
   `hhat(m_iP)=m_i^2 hhat(P)`；当 `n>=72` 时把可能的 `m_i` 压缩到
   极少数组合；
3. 对每种组合把等差条件化成无有理根的多项式；
4. 对 `n<72` 显式求完所有整点并枚举。

因此它主要是排除法，不是生成二倍点等差列的参数化。论文研究的普通
整点等差列只满足 `Q_i in E(Q)`；平方幻方还要额外满足
`Q_i in 2E(Q)`，这层 Kummer 条件在搜索中必须最先加入。

顺便校正一处二手资料中的笔误：`E_n:y^2=x^3-n^2x` 的 `j`-不变量是
`1728`，不是 `0`。因此固定 `j` 的长等差列定理应在 `j=1728` 处应用。

## 3. 低次数域得到的结构性结论

### 3.1 三次域不能靠有理点扩域

若 `L/Q` 是奇数次扩张，而有理数 `r` 在 `L` 中成为平方，则
`Q(sqrt(r))` 是 `L` 的次数至多二的子域；塔式定理迫使 `r` 已是有理
平方。因此，对 `n in Q` 和 `Q in E_n(Q)`，

```text
Q in 2E_n(L)  iff  Q in 2E_n(Q)       ([L:Q] odd).
```

所以 BST 找到的有理整点等差列若在 `Q` 上不是三个二倍点，扩张到任何
三次域也不会变成三个二倍点。三次域方案必须有真正的三次 `x` 坐标（或
真正的三次参数 `n`），而不能只是给有理幻方项补平方根。

此外，三个有理 2-扭点的可除性分别要求

```text
(0,0) in 2E_n(K)    => -1 is a square in K,
( n,0) in 2E_n(K)   =>  2 is a square in K,
(-n,0) in 2E_n(K)   =>  2 is a square in K.
```

三次域没有二次子域，故目标等差列中的三个二倍点都不可能是 2-扭点。

### 3.2 二次域的扭点分支只剩两个域，且 BST 有理参数族仍被排除

在二次域中，中间扭点 `(0,0)` 只有在 `K=Q(i)` 才可能被二除；端点扭点
`(+-n,0)` 只有在 `K=Q(sqrt(2))` 才可能被二除（还需相应的 `n` 平方类
条件）。对正的有理 `n`，`(-n,0)` 在实二次域中不可能被二除，所以 BST
定理 1.3 的有理扭点参数族若可能有用，只能是包含 `(n,0)` 的分支。

BST 定理 1.3 的参数为

```text
n = 3(r^2+s^2)(r^2-2s^2)(2r^2-s^2)t^2,  gcd(r,s)=1.
```

模 3 检查表明三个括号因子都不被 3 整除：若 `r,s` 均不被 3 整除，
二者平方均为 1；若一个被 3 整除，直接代入也非零。因此 `v_3(n)` 的
奇偶性恒为 1，乘上 `t^2` 不改变它。可是 `(n,0)` 在 `Q(sqrt(2))` 中被
二除要求 `n` 的有理平方类为 `1` 或 `2`。两者矛盾，故 BST 定理 1.3
的全部有理扭点等差列都不能产生二次域平方幻方。

### 3.3 已知的 `n=1254` 非扭整点等差列也不够低次

论文列出的唯一一个三点均非扭的整点例子是 `E_1254` 上

```text
x=-528, -363, -198.
```

其三个 Kummer 平方类三元组分别为

```text
(-22,-33, 6), (-33,-3,11), (-3,-22,66).
```

每个点单独需要两个独立平方类，三个点合起来生成维数 3 的平方类群。
因此同时把它们变成二倍点的最小多二次扩张次数为 `2^3=8`；它既不能
给出二次域例子，也不能给出三次域例子。计算由 `bst_number_field.py`
精确复核。

## 4. BST 方法怎样改造成有用的搜索

### 二次域：最可行

先固定 `K=Q(sqrt(d))` 和有理 `n`。有秩分解

```text
rank E_n(K) = rank E_n(Q) + rank E_{dn}(Q),
```

因为 `E_{dn}` 是 `E_n` 的二次扭曲。可据此优先选择秩至少二的曲线。
对每个候选点先做 Kummer 筛选：所有有理 Kummer 平方类必须属于
`{1,d}`；对非有理点则直接在 `K*/K*2` 中检查。随后用数域上的规范高度
和 Mordell--Weil 高度配对矩阵枚举 `2E_n(K)` 中的整点，再用哈希查找
`x_0-2x_1+x_2=0`。BST 的高度“夹逼”思想可以在这里实用化。

若只扫描 BST 或其他文献中的有理整点等差列，则平方类维数大于 1 的
候选可立即丢弃。这是成本很低而很强的前置筛选。

### 三次域：必须重建数域版高度枚举

三次域没有上述两个二次扭曲的秩分解，也不能从有理点获得新的二可除性。
应固定一个小判别式三次域和 `n in O_K`，直接计算 `E_n(K)/2E_n(K)` 与
Mordell--Weil 基，再在 `2E_n(K)` 中枚举整点。BST 的三步仍可作为框架，
但不能原样照搬：

- 有多个实/复嵌入，不能使用 `Q` 上单一的大小次序；
- 分母变成理想，单位群会造成某个嵌入很小、另一个很大的失衡；
- 高度常数依赖域判别式、调节子和 `n` 的理想，而不再有统一的
  `n>=72` 分界；
- 最后的“无有理根”要改为在 `K` 中因式分解或用局部素理想排除。

所以这篇论文对三次域的价值主要是证明策略和高度剪枝，而不是现成定理。

## 5. 当前优先级

1. 扫描公开的有理整点 AP 数据，并计算联合 Kummer 平方类秩；秩 0 是
   有理解，秩 1 直接给二次域候选，秩大于 1 立即淘汰。
2. 对 `Q(sqrt(d))` 用扭曲秩公式选择 `rank>=2` 的 `(d,n)`，在
   `2E_n(K)` 而不是整个 `E_n(K)` 中做高度有界整点枚举。
3. 三次域只搜索真正三次坐标；优先小判别式域，并利用“无扭点、无有理
   点扩域捷径”两个结论缩小空间。
