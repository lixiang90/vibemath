## 1. 结论

本轮有两个严格升级。

第一，`z(H)` 不再以一条人类字符串表示。其所在的 étale 代数、二次数域乘法、两个分量、共轭、范数及从大 Jacobian 到小模型的缩放全部成为结构化 JSON 字段并由测试逐项重算。

第二，旧报告的 `8+4` 不再只是“通过已列坏位的 ambient 类”。标准支撑引理证明 Selmer 类只需在相应 `b` 的素因子上枚举；标准好素数引理证明未列素数自动有局部点。因此此前 512 格矩阵已经检查了全部必要位置，严格得到

```text
Sel^(dual_phi)(E'/Q) = <3,5,7>,       dimension 3,
Sel^phi(E/Q)         = <4230241,339106321>, dimension 2.
```

这里第一群以 E 上的 `x`-Kummer 类表示，第二群以 E' 上的 `x`-Kummer 类表示。于是

```text
rank E(Q) <= 3+2-2 = 3.
```

这是真正的 2-同源 Selmer 上界，但不是精确 Mordell--Weil rank。

二进四次不变量给大模型

```text

```

用

```text
x_big=64^2*x_small,
y_big=64^3*y_small
```

得到

```text
y^2=x^3-58243635870855147*x
        -3811211217040595260188186.
```

再令 `X=x_small+197298357`，精确展开为

```text
E: y^2=X^3-591895071*X^2+58536289153843200*X.
```

有理预解根满足

```text
-3*phi_0=64^2*(-197298357),
```

因此完整 `z(H)` 在有理 2-挠分量上的投影确为 E 侧 `[X]=35`。该结论只识别投影；`C_H` 并不因此与标准偶四次 `C_35` 同构。

## 4. 为什么 `8+4` 现在是精确 Selmer 群

### 4.1 支撑完整性

对

```text
E_{a,b}: y^2=x^3+a*x^2+b*x
```

标准 `x`-Kummer 类 `d` 的齐次空间是

```text
C_d: N^2=dU^4+aU^2V^2+(b/d)V^4.                 (4.1)
```

取 `d` 的平方自由整数代表。若 `p` 不整除 `b` 而 `v_p(d)=1`，把 `(U,V)` 规范为至少一个 p-adic unit：

- 若 `V` 是 unit，(4.1) 右端唯一最低项 `(b/d)V^4` 的赋值为 `-1`，不可能是平方；
- 故 `p|V` 且 `U` 是 unit；此时最低项 `dU^4` 的赋值为 `1`，仍不可能是平方。

所以任一 Selmer 类在 `p∤b` 处赋值为偶，可由 `b` 的带符号平方自由因子表示。由此 E 侧恰有原始 `32` 个候选，E' 侧也恰有 `32` 个候选，而不是只搜索了一个任意子集。

### 4.2 好素数自动局部可解

令

```text
S={infinity,2} union primes dividing b*(a^2-4b).
```

若 `p` 不在 `S`，则 `p>=5`，`d,b/d` 均为 units，(4.1) 的光滑射影模型在 `F_p` 上是 genus 1。Hasse 界给

```text
#C_d(F_p) >= p+1-2*sqrt(p) > 0.
```

所有模 p 点均光滑，Hensel 引理给 `C_d(Q_p)` 非空。因此只需检查 `S`。

本题两侧的共同集合恰为

```text
S={infinity,2,3,5,7,59,71699,339106321},
```

即旧 512 格证书的八列。每个幸存类在每一列都有实际局部点；每个淘汰类至少有一个严格局部阻碍。故最终集合精确是

```text
E side:
  {1,3,5,7,15,21,35,105}=<3,5,7>;

E' side:
  {1,4230241,339106321,1434501462453361}
  =<4230241,339106321>.
```

若 `phi:E->E'` 的核是 `{O,(0,0)}`，则 E 上 Kummer 集合按通常方向记为 `Sel^(dual_phi)(E'/Q)`，E' 上集合记为 `Sel^phi(E/Q)`。两群维数为 3 与 2。标准两同源精确序列给 rank 上界 `3+2-2=3`。

## 5. 已知 Mordell--Weil Kummer 像与 Sha 候选

本轮只使用能够直接代回方程证明的点：无穷远点和可见有理 2-挠点。

```text
alpha_E(O)=1,
alpha_E((0,0))=[b]=[7];

alpha_E'(O)=1,
alpha_E'((0,0))=[b']=[1434501462453361].
```

所以当前已证明的 MW 像子群仅为

```text
E:  {1,7},
E': {1,1434501462453361}.
```

Selmer 群模这些已知子群后的未解释陪集为

```text
E:  {1,7}, {3,21}, {5,35}, {15,105};
E': {1,D}, {4230241,339106321}.
```

这些只是“MW 或 Sha 尚未区分”的候选。未知非挠有理点可能解释其中部分或全部，故不得称它们为已经证明的非零 Sha 类。Campbell 投影 `35` 位于 E 侧 `{5,35}` 陪集。

## 6. `d=35` 的 Cassels--Tate / TwoCoverDescent 闸门

对应标准覆盖为

```text
C_35:
N^2=35U^4-591895071U^2V^2+1672465404395520V^4.    (6.1)
```

其在 `S` 的全部局部点输入已从 JSON 矩阵逐格嵌入新证书。由于对偶 Selmer 群模已知挠点像只有一维，实际只需计算两项（两项由双线性关系相关，但保留双重校验）：

```text
<35,4230241>_CT,
<35,339106321>_CT.
```

标准显式公式是：先在 (6.1) 关联的 conic 上构造有理点及其切线形式 `L_35`，对每个 `v in S` 选证书中的局部点 `P_v`，再计算

```text
<35,e>_CT = product_{v in S} (L_35(P_v),e)_v,
```

其中右侧为局部 Hilbert symbol。若任一配对非零，就证明 `35` 不在 E 的 Mordell--Weil Kummer 像；因 `C_H` 的完整 2-cover 类投影到 `35`，这将给出 `C_H(Q)=empty` 的严格阻碍。

当前没有构造出可审计的全局 conic 点/切线形式，也没有可信 `TwoCoverDescent` 或 Cassels--Tate transcript。因此两个 pairing bit 都保持

```text
UNKNOWN_FAIL_CLOSED.
```

`PAPER_ELLIPTIC_ROUND_04_two_cover_descent.m` 固定了 `C_H` 的无 cutoff `TwoCoverDescent` 输入和两个配对目标，但其本身不是计算结果。精确剩余阻断已经从“12 个 Selmer 类未知”缩小为：

1. 求 (6.1) 关联 conic 的一个 Q-点和切线 `L_35`，再算至多两个 Hilbert-symbol 乘积；或
2. 获得经独立审批的真实 `TwoCoverDescent(C_H)` 输出，并把返回类与结构化 `Q x K` 元素逐分量比较。
