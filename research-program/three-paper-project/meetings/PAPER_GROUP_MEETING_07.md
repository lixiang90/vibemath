# 第七次论文组会：三个低风险增量成果

日期：2026-09-03
主持：导师（root）
结论：三条支线各取得一个可独立复核的严格增量；Goal 保持 `ACTIVE`

## 1. 甲线：mask 99 将候选从 23 降到 15

对支撑集 `{0,1,5,6}`，需研究

`y^2 = t(t+1)(t+5)(t+6)`。

令 `A=t(t+6)`、`B=(t+1)(t+5)=A+5`。因 `gcd(A,B)|5`，在
`t<=-7` 或 `t>=1` 时，若 `AB` 为平方，则 `A`、`B` 的共同无平方因子核只能是
`1` 或 `5`。核为 `1` 时得到 `V^2-U^2=5`，进而 `A=4`，但
`(t+3)^2=13` 模 8 不可能；核为 `5` 时得到 `V^2-U^2=1`，迫使
`U=0`，与 `A>0` 矛盾。中间七个整数逐一代入，只得到含零的退化点或
`t=-3, y=+-6`，而相应七项块仍含零。

因此 mask 99 排除 8 个旧候选，严格筛链更新为

`651 -> 343 -> 284 -> 98 -> 54 -> 35 -> 23 -> 15`。

剩余 ID 为

`12, 31, 33, 43, 59, 83, 134, 214, 230, 251, 257, 268, 276, 281, 283`。

边界：这仍是必要条件筛，不证明 15 个模式可实现，也不决定 `R_2(7)`。

## 2. 乙线：首个四命中模型的正秩无穷族

位置 `(0,1,3,4)`、颜色 `0001` 对应光滑平面三次曲线

`C: 2X^3 - 3Y^3 + Z^3 = 0`。

取原点 `O=(1:1:1)` 和点 `P=(4:1:-5)`。显式有理映射把 `C` 映到

`E: v^2 = u^3 - 243`，

其中 `O` 映到 `-Q`、`P` 映到 `2Q`，`Q=(7,10)`。由 Nagell--Lutz，
`10^2` 不整除该整模型的判别式 `-2^4*3^13`，故 `Q` 非挠。以 `O` 为原点平移后，
`P` 映到 `3Q`，所以 `P` 在 `C(Q)` 上非挠。排除有限个零项、常数项和退化点后，
倍点给出无穷多个不等价的五项有理等差数列，在同一非平凡纯三次域中恰有四项为立方。

最小展示例为

`(64, 1, -62, -125, -188)` over `Q(cuberoot(188))`。

边界：这只解决 31 个四命中模型中的一个，不声称给出完整 Mordell--Weil 群或全部
四命中等差数列分类。

## 3. 丙线：精确全局极小模型与导子

原 Campbell 模型经

`x_old=36*x_min`，`y_old=216*y_min+108*x_min`

变为

`y^2 + x*y = x^3 - 16441530*x^2 + 45166889779200*x`。

精确整数计算给出

`c4 = 2157171698920561`,

`Delta_min = 2^28*3^16*5^4*7^10*59*71699*339106321`。

由于 `gcd(c4,Delta_min)=1`，每个坏素数处均为乘法约化，导子指数为 1，故

`N = 2*3*5*7*59*71699*339106321 = 301245307115205810`。

这给出可搜索的精确同构类指纹，但当前 LMFDB 搜索范围不足以据此作新颖性结论；
数据库级人工查重仍是投稿门槛。
